# Mods

Citron is tested as a curated set of mods and configurations. You can customise it, but extra mods may cause conflicts, duplicate features, or change performance.

Pick the guide that matches what you're trying to do.

{% hint style="warning" %}
Be careful when removing mods that came with Citron. Some provide features you use; others are required by another mod. If you want to return to the original setup, a fresh instance is often safer than trying to put everything back by hand.
{% endhint %}
