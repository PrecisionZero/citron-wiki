# Removing Mods

If a mod you added yourself is causing problems, remove that one first and test again. Removing a mod that came with Citron is different: it may provide a feature you use or a dependency that another mod needs.

{% tabs %}
{% tab title="Modrinth App" %}
1. Open **Library** and select Citron.
2. Open the instance's installed content list.
3. Find the mod and use its enable/disable control, if available.
4. Restart Citron and check whether the problem is fixed.
{% endtab %}

{% tab title="CurseForge App" %}
When Citron is available on CurseForge:

1. Open **Minecraft → My Modpacks** and select Citron.
2. Open the menu → **Profile Options**.
3. Enable **Allow content management for this profile** and click **Done**.
4. Open the installed mods list and toggle the mod off.
5. Launch Citron and test again.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Don't disable libraries or dependencies just because their purpose isn't obvious. Removing them can stop other mods from working—or stop the game from launching entirely.
{% endhint %}

If you've removed several mods and aren't sure what changed, install a fresh Citron instance and copy your personal files back in. That's usually quicker than reconstructing the original setup.
