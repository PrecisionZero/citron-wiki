# Adding Mods

Citron already has a curated set of mods, but you can add your own. Just check that the mod supports the same Minecraft version and Fabric loader as your Citron build, and make sure Citron doesn't already include the feature you need.

{% tabs %}
{% tab title="Modrinth App" %}
1. Open **Library** and select Citron.
2. Click **+ Install content**.
3. Search for the mod you want.
4. Check that the version supports your Minecraft version and Fabric, then click **Install**.
5. Launch Citron and test it before adding another mod.
{% endtab %}

{% tab title="CurseForge App" %}
When Citron is available on CurseForge, you can add mods through the profile's content browser.

1. Open **Minecraft → My Modpacks** and select Citron.
2. Open the menu → **Profile Options**.
3. Enable **Allow content management for this profile** and click **Done**.
4. Open **Add More Content** (the puzzle-piece button), then search for a compatible mod.
5. Click **Install**, then launch Citron and test it.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Install one mod at a time. If the game crashes or a feature stops working, remove the last mod you added and test again. Some mods need extra dependencies, and others may conflict with mods already in Citron.
{% endhint %}

If you download a `.jar` manually, make sure it goes into the `mods` folder for the Citron instance—not another Minecraft installation.
