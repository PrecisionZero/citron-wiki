# Compatibility and Servers

Citron is designed to run on your client, so a multiplayer server generally doesn't need Citron installed. That doesn't automatically mean every server allows every mod or feature in the pack.

## Before joining a server

* Read the server's rules about client-side mods and gameplay advantages.
* If you're unsure about a particular mod or feature, ask the server staff before using it.
* Remember that staff have the final say, even if a mod is allowed on other servers.

## If you can't join

First check the server's Minecraft version against the version of Citron you're using. If the versions match, try joining with a clean Citron instance and without extra mods you've added.

Citron's feature set can change between builds, so a feature accepted by one server may not be accepted by another. See the [Disclaimers](../disclaimers.md) for the project's full guidance.
