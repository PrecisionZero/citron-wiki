# Configurations and Settings

Citron ships with selected configurations intended to make its included mods work well together. Defaults may change between builds as mods and compatibility requirements change.

You can adjust settings to suit your preferences. If you're troubleshooting a problem, test with the original Citron settings first; this helps separate a problem in the pack from a change you made yourself.

## If a setting changes after an update

1. Check the version notes to see whether the configuration was changed intentionally.
2. Open the relevant in-game settings screen and restore your preference, if possible.
3. If you edit config files manually, close Minecraft first and keep a backup of the original file.
4. Change only the relevant setting rather than deleting the entire configuration folder.

{% hint style="warning" %}
Deleting the whole `config` folder can reset unrelated mods and make troubleshooting more difficult. Keep a backup and change only what you need.
{% endhint %}
