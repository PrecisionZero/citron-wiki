# Shaders

Before installing a shader, check that your Citron build includes a compatible shader loader. Citron's development history records Iris Shaders, but support can change between builds.

{% stepper %}
{% step %}
## Check your Citron build

Launch the game and open **Options → Video Settings**. If a **Shader Packs** screen is available, a compatible shader loader is working.
{% endstep %}

{% step %}
## Download a shader pack

Choose a shader that supports your Minecraft version and graphics setup. Use a source you trust and read the pack's requirements before installing it.
{% endstep %}

{% step %}
## Add and enable it

Open **Shader Packs**, use its folder option if needed, and add the shader ZIP. Return to the list, select the pack, and apply it.
{% endstep %}
{% endstepper %}

## If shaders are missing or crash

Confirm that the loader is available in your Citron version, then test without other shaders or extra mods. Shaders can be demanding even on a well-optimised setup; if performance drops too much, disable the shader or lower its settings.

{% hint style="info" %}
A shader pack is an optional addition, not a requirement for using Citron. Test the base modpack first so you have a known-good setup to return to.
{% endhint %}
