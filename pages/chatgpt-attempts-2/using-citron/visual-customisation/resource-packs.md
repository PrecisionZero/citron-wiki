# Resource Packs

Resource packs change textures, sounds, and other parts of Minecraft's presentation. Use packs that support your Minecraft version.

{% stepper %}
{% step %}
## Download a pack

Download the resource pack from a source you trust. Check the supported Minecraft version and whether the pack requires special features or mods.
{% endstep %}

{% step %}
## Open the Resource Packs menu

Launch Citron and open **Options → Resource Packs**. Use **Open Pack Folder** to find the correct folder for this instance.
{% endstep %}

{% step %}
## Add and enable the pack

Place the downloaded resource-pack file in the folder, return to Minecraft, and enable it. If multiple packs change the same textures, their position in the list determines which changes take priority.
{% endstep %}
{% endstepper %}

## If something looks wrong

Disable other resource packs and test the new one by itself. Check whether it depends on OptiFine-specific features or another rendering mod that your Citron build does not include. If the problem started after an update, check the version notes and test with a clean pack list.
