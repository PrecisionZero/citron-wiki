# First Launch

The first launch is best kept simple. Start Citron as installed before adding extra mods, shaders, or resource packs. That way, you'll know the base pack works before making changes.

{% stepper %}
{% step %}
## Launch Citron

Open your Citron instance from the launcher. The first launch can take longer while Minecraft loads the included mods.
{% endstep %}

{% step %}
## Check the main menu

Citron uses a custom menu. If you need a button that isn't there, use **Default Menu** to switch to Minecraft's default menu.
{% endstep %}

{% step %}
## Set your controls

Open **Options → Controls** and change anything you need. If you want to find a mod's keybind, use the search field rather than scrolling through the whole list.
{% endstep %}

{% step %}
## Start a world

Load a world or join a server. If everything works, you now have a clean setup to return to if a later change causes problems.
{% endstep %}
{% endstepper %}

## Memory allocation

Giving Minecraft more memory doesn't automatically improve performance. Too much can leave Windows and other applications short of memory.

| Allocation  | Amount |
| ----------- | -----: |
| Minimum     |   2 GB |
| Recommended |   4 GB |
| Maximum     |   6 GB |

For typical Citron use, allocating more than 4 GB is unlikely to make a noticeable difference.

{% hint style="info" %}
If Citron runs well with your launcher's default setting, you don't need to change memory allocation just because the option is there.
{% endhint %}

Once the game works, add shaders, resource packs, or extra mods one at a time. If something breaks, it'll be easier to find the cause.
