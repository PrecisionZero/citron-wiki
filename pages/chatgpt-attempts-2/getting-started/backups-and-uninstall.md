# Backups and Uninstall

Before updating Citron, switching Minecraft versions, or removing an instance, copy the files you want to keep **somewhere outside the instance folder**. If your only backup is inside the instance, deleting it may delete the backup too.

## What should I back up?

| File or folder  | Contains                               |
| --------------- | -------------------------------------- |
| `saves`         | Your single-player worlds              |
| `screenshots`   | Screenshots you've taken               |
| `resourcepacks` | Resource packs you've added            |
| `shaderpacks`   | Shader packs you've added              |
| `servers.dat`   | Your saved multiplayer server list     |
| `options.txt`   | Video options and keybinds             |
| `config`        | Personal changes to mod configurations |

You may also want to save any mods you've added yourself. Don't copy the entire old `mods` folder into a new version without checking compatibility first.

{% tabs %}
{% tab title="Modrinth App" %}
1. Open **Library** and find Citron.
2. Right-click the instance, or open its menu, and choose **Open folder**.
3. Copy the files and folders you want to keep to Documents, Desktop, or another safe location.
4. To remove Citron, use the instance menu → **Delete** and read the confirmation before proceeding.
{% endtab %}

{% tab title="CurseForge App" %}
Once Citron is available on CurseForge:

1. Open **Minecraft → My Modpacks**.
2. Right-click Citron and choose **Open Folder**.
3. Copy the files and folders you want to keep somewhere safe.
4. To uninstall, use the profile menu → **Delete Profile** and check the confirmation before deleting its files.
{% endtab %}
{% endtabs %}

## Restoring your files

Install Citron again, launch it once, and then copy your worlds and personal files into the new instance. Restore configuration files selectively—an old config may not work with a newer version of a mod.
