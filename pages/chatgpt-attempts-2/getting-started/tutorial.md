# Tutorial

Already downloaded Citron? Here's the basic setup to get you into the game without messing around with extra settings first.

{% stepper %}
{% step %}
## Install Citron

Choose your launcher and follow the [Installation guide](../../installation/). Make sure the build matches the Minecraft version you plan to play.
{% endstep %}

{% step %}
## Launch the instance

Open Citron from your launcher and wait for the main menu. The first launch can take a little longer while Minecraft loads the mods.
{% endstep %}

{% step %}
## Check the menu

Citron uses a custom main menu. If a button you need isn't there, use **Default Menu** to switch to Minecraft's normal menu.
{% endstep %}

{% step %}
## Set up your controls

Open Controls and change anything you need. If a mod adds a keybind, use the search box to find it rather than scrolling through every entry.
{% endstep %}

{% step %}
## Play before adding extras

Start a world or join a server before adding extra mods, resource packs, or shaders. If Citron works as installed, you have a clean setup to return to if a later change causes trouble.
{% endstep %}
{% endstepper %}

If something goes wrong, start with [Troubleshooting](../help/troubleshooting.md). For more about Citron's features, see [Features and Options](../features-and-options/).
