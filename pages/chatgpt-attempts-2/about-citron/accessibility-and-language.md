# Accessibility and Language

Citron's custom main menu does not show Minecraft's **Language** or **Accessibility** buttons in the documented `1.0.0-dev.8+mc1.21.11.fabric` build. You can still reach those options by switching to Minecraft's default menu with **Default Menu**.

From there, open **Options → Accessibility Settings** or **Language** to use Minecraft's built-in settings. The exact options depend on the Minecraft version you're playing.

If you rely on a specific accessibility setting, check it after installing or updating Citron. The custom menu can change between builds, so report any missing control with your Citron build ID and the steps needed to reproduce the issue.
