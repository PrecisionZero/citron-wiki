# Accessibility and Language

Citron's custom main menu does not show Minecraft's **Language** or **Accessibility** buttons in the documented `1.0.0-dev.8+mc1.21.11.fabric` build. You can still reach those options by switching to Minecraft's default menu with **Default Menu**.

{% stepper %}
{% step %}
## Switch menus

From Citron's custom menu, select **Default Menu**.
{% endstep %}

{% step %}
## Open Options

Select **Options** from Minecraft's default menu.
{% endstep %}

{% step %}
## Choose a setting

Open **Accessibility Settings** or **Language** and make the change you need.
{% endstep %}
{% endstepper %}

The exact settings depend on the Minecraft version. If you rely on a particular accessibility option, check it after installing or updating Citron, since the custom menu may change between builds.

If a menu option is missing or the switch button does not work, see [Changed Options](../features-and-options/changed-options.md) or include your Citron build ID when [reporting an issue](../help/report-an-issue.md).
