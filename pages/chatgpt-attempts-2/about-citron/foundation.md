# Foundation

### Thank you, Adrenaline.

To start it off, I want to express my gratitude towards [**Adrenaline**](https://modrinth.com/modpack/adrenaline), the baseline modpack Citron is built on. Without it, we'd be in a completely different place by now.

Citron's foundation and update cycle rely heavily on Adrenaline. When Adrenaline updates to a newer Minecraft version or releases a patch for an existing one, you can usually expect Citron to follow after the changes have been checked and tested.

### Don't Reinvent the Wheel

Citron has its own direction, but that doesn't mean I need to start from zero. Adrenaline provides the performance foundation; Citron builds on it with its own features, configurations, and quality-of-life improvements based on [its philosophy](my-philosophy.md).

I don't want to make Citron another Adrenaline. I want to make a pack that brings players a convenient experience without making them set everything up themselves.

At the end of the day, what matters isn't the time spent setting up the environment. It's what you, the player, decide to do with it.
