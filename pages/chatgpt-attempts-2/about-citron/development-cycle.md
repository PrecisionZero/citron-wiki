# Development Cycle

Citron is built on Adrenaline's performance foundation. When Adrenaline updates to a newer Minecraft version or releases a patch, Citron can usually follow—but the changes still need to be checked and tested first.

I don't want to make Citron another Adrenaline. The point is to use a foundation that already works, then build Citron's own selection of features, configurations, and quality-of-life improvements on top of it.

Development builds use an ID like `1.0.0-dev.8+mc1.21.11.fabric`. The `dev.N` value advances with each development build; the Minecraft version and loader are recorded in the rest of the ID. Original build IDs are kept in the development records so older changes can still be traced.

For build-specific information, see [Versions and Builds](../versions-and-builds/) and the [development log on GitHub](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md).
