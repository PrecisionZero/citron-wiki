# Troubleshooting

Before changing lots of files, try to reproduce the problem with a clean Citron instance. That helps show whether it's Citron itself or a mod, shader, resource pack, or setting you've added.

{% tabs %}
{% tab title="The game won't launch" %}
1. Check that you installed a Citron build for the Minecraft version you want to play.
2. Restart the launcher and try again.
3. Temporarily remove extra mods, shaders, and resource packs.
4. Check the launcher's error message and game log for the first relevant error.
5. Make sure enough memory is available for both Minecraft and Windows.
{% endtab %}

{% tab title="A feature or button is missing" %}
1. Check the page for your exact Citron build.
2. Switch to Minecraft's default menu if a button is missing from the Citron menu.
3. Check whether a personal setting or configuration change disabled the feature.
{% endtab %}

{% tab title="Performance is poor" %}
1. Test without shaders or extra mods.
2. Lower render distance or other demanding video settings.
3. Close programs you don't need while playing.
4. Compare the same world and settings before deciding an update caused a regression.
{% endtab %}

{% tab title="Resource packs or shaders look wrong" %}
1. Disable other packs and shaders.
2. Check compatibility with your Minecraft version and rendering setup.
3. Add your packs back one at a time to find what causes the problem.
{% endtab %}
{% endtabs %}

If the issue started after an update, check the version notes and test without personal additions. If it still happens, follow [Report an Issue](report-an-issue.md) and include your build ID and relevant log.
