# FAQ

## Is Citron client-side?

Yes. Citron is designed to run on the player's client, so a server generally doesn't need Citron installed. Individual servers may still restrict particular mods or features, so check their rules before joining.

## Is Citron a performance-only modpack?

No. Citron combines performance improvements with quality-of-life and convenience features. If you're looking for a pack focused more narrowly on performance, I'd recommend checking out Adrenaline.

## Can I add my own mods?

Yes, but extra mods can introduce conflicts, duplicate features, or change performance. Back up your instance and add mods one at a time. Check that each mod supports the Minecraft version and Fabric loader used by Citron.

## Why are some buttons missing from the main menu?

Citron uses a custom menu. Switch to **Default Menu** to reach buttons that aren't shown there, including Language and Accessibility in the documented development build.

## Why did a setting change after an update?

Some configuration defaults can change between builds. Check the version notes and restore your personal preference if it was reset.

## Where can I find what changed in a build?

Visit [Versions and Builds](../versions-and-builds/) for the version index and build support. Detailed changes are also recorded in the [Citron development history on GitHub](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md).

## Can I use Citron on multiplayer servers?

Citron is client-side, but server rules still apply. Read the server's policies about client-side mods and ask staff if you're unsure.
