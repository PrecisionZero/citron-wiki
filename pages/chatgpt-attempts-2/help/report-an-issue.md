# Report an Issue

Before reporting a problem, check the [Troubleshooting](troubleshooting.md) guide and the notes for your Citron version. If possible, reproduce it on a clean instance without extra mods, shaders, resource packs, or personal configuration changes.

## Include these details

* **Citron version/build ID:** Copy the exact identifier shown on the version or download page.
* **Minecraft version and loader:** Include the versions shown for your instance.
* **What happened:** Describe the problem in a sentence or two.
* **How to reproduce it:** List the steps that trigger the problem.
* **Logs or crash report:** Attach the relevant file or share a link from a trusted log-hosting service.
* **Extra changes:** Mention any mods, shaders, resource packs, or config edits you added.

## Before you submit

1. Check whether the same problem has already been reported.
2. Test without your own additions.
3. Include only the log or screenshot needed to investigate the issue.
4. Remove account tokens or private information from logs before sharing them.

<a href="https://github.com/PrecisionZero/citron/issues/new/choose" class="button primary" data-icon="github">Open the Citron issue tracker</a>

A short, reproducible report is much more useful than a long description without the details needed to investigate it.
