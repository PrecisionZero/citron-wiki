# Report an Issue

Before reporting a problem, check the [Troubleshooting](troubleshooting.md) guide and the notes for your Citron version. If possible, reproduce it on a clean instance without extra mods, shaders, resource packs, or personal configuration changes.

## Include these details

* **Citron version/build ID:**
* **Minecraft version:**
* **Launcher:**
* **What happened:**
* **What you expected:**
* **Steps to reproduce:**
* **Relevant log, crash report, or screenshot:**

A short report that can be reproduced is much more useful than a long description without the details needed to investigate it. Don't upload private account information or unrelated personal files.

<a href="https://github.com/PrecisionZero/citron/issues/new/choose" class="button primary" data-icon="github">Report an issue on GitHub</a>

{% hint style="info" %}
If you can only reproduce the problem after adding another mod, include its name and version too. That helps distinguish a Citron issue from a compatibility issue.
{% endhint %}
