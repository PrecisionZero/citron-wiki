# Included Mods

Citron is built around the **features** its mods provide, rather than treating a fixed mod list as the identity of the pack. Still, it's useful to know which projects have been part of its development.

The list below comes from the repository's development history. It records mods added during development; it is **not a verified manifest of the latest downloadable build**. Check the exact version you're using before assuming every entry is still included.

## Recorded in the initial development build

## Added in later development builds

* **Status Effect Timer** — recorded in `1.0.0-dev.2`.
* **Mouse Tweaks** and **LambDynamicLights** — recorded in `1.0.0-dev.3`.
* **FancyMenu**, **Konkrete**, and **Melody** — recorded in `1.0.0-dev.5` as part of the custom-menu work.

The repository also records **Simple Menu** being added in `dev.4` and removed in `dev.5` when the menu implementation changed.

{% hint style="info" %}
This page follows the development records, not a live scan of every mod inside a published file. Mod versions and the included feature set can change between builds.
{% endhint %}
