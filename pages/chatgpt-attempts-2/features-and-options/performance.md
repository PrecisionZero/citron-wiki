# Performance

Citron includes performance improvements, but performance isn't the only goal. The pack also includes quality-of-life features, so it's not meant to be the most minimal performance-only setup.

Results depend on your hardware, Minecraft version, world, render distance, video settings, shaders, and other programs running at the same time. Citron can't promise a particular FPS on every machine.

## If Minecraft feels slow

Start with [Performance Tips](../using-citron/performance-tips.md). The first things to test are render distance, simulation distance, shaders, and any extra mods you've installed.

## Compare builds fairly

Use the same world and settings when comparing two versions. Let the world load before measuring, and repeat the test instead of judging it from one FPS reading.

For build-specific information, see [Versions and Builds](../versions-and-builds/).
