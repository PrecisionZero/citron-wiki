# Feature Index

Citron is built around the features that make everyday Minecraft more convenient. The point isn't to include as many mods as possible; it's to choose the right tools for the job.

This list is based on the development records for `1.0.0-dev.1` to `1.0.0-dev.8`. It shows what has been recorded during development, not a guarantee that every entry is present in every future build.

## Quality of life

| Feature              | What it does                                                    | Provided by                                                       |
| -------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| Zoom                 | Zoom in on distant details.                                     | [Zoomify](https://modrinth.com/mod/zoomify)                       |
| Shulker box previews | View shulker-box contents from your inventory.                  | [Shulker Box Tooltip](https://modrinth.com/mod/shulkerboxtooltip) |
| Food information     | See extra hunger and saturation information.                    | [AppleSkin](https://modrinth.com/mod/appleskin)                   |
| Status effect timers | See how much time remains on active effects.                    | [Status Effect Timer](https://modrinth.com/mod/statuseffecttimer) |
| Inventory handling   | Move items around with additional mouse actions.                | [Mouse Tweaks](https://modrinth.com/mod/mouse-tweaks)             |
| Dynamic lighting     | Light up nearby surroundings with supported items and entities. | [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights)   |
| Durability tooltips  | See item durability in a tooltip.                               | [Durability Plus](https://modrinth.com/mod/durability-plus)       |
| Keybind search       | Search the Controls menu for a binding.                         | [Controlling](https://modrinth.com/mod/controlling)               |

## Interface and visuals

| Feature                | What it does                                                | Provided by                                                |
| ---------------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| Debug screen layout    | Make the F3 debug screen easier to read.                    | [BetterF3](https://modrinth.com/project/betterf3)          |
| Player list            | Make the tab list scrollable and show numeric ping.         | [Better Tab](https://modrinth.com/project/bettertab)       |
| Armor HUD              | Display armor and durability information on the HUD.        | [uku's Armor HUD](https://modrinth.com/mod/ukus-armor-hud) |
| Visual comfort options | Adjust brightness, fog, overlays, and other visual details. | [BactroMod](https://modrinth.com/mod/bactromod)            |
| Extra video options    | Change more animations, particles, and rendering details.   | [Sodium Extra](https://modrinth.com/mod/sodium-extra)      |
| Connected textures     | Support connected textures in compatible resource packs.    | [Continuity](https://modrinth.com/mod/continuity)          |

## Performance and menus

Citron builds on Adrenaline's performance foundation and includes performance-related mods recorded during development, such as BadOptimizations and Clumps. Its custom main menu is built with [FancyMenu](https://modrinth.com/mod/fancymenu).

* [Changed Options](changed-options.md) explains the main-menu differences.
* [Included Mods](included-mods.md) lists the projects recorded in the development history.
* [Performance](performance.md) covers what to expect and how to compare results.
