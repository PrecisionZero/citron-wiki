# Changed Options

Citron uses a custom main menu. It keeps the layout focused, but it doesn't show every button from Minecraft's default menu.

## Main menu differences

| Option                      | Citron menu                     | Minecraft's default menu |
| --------------------------- | ------------------------------- | ------------------------ |
| Language                    | Not shown                       | Available                |
| Accessibility               | Not shown                       | Available                |
| Buttons added by other mods | Hidden to keep the layout clean | Shown                    |
| Citron version note         | Shown                           | Hidden                   |
| Switch between menus        | **Default Menu**                | **Citron Menu**          |

If a button is missing, switch to the default menu before assuming the option isn't available.

## Settings after an update

Citron also ships with selected mod configurations. Those may change as mods are updated or compatibility issues are addressed. After updating, check the settings you rely on and restore your personal preferences if something was reset.

{% hint style="info" %}
This table reflects the documented `1.0.0-dev.8+mc1.21.11.fabric` development build. Later builds may change the menu or configuration defaults.
{% endhint %}

For the available controls, see [Accessibility and Language](../about-citron/accessibility-and-language.md).
