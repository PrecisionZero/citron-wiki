# Foundation

To start it off, I want to express my immense gratitude towards [**Adrenaline**](https://modrinth.com/modpack/adrenaline), the baseline modpack Citron is built off from. Without it, we'd be in a completely different place by now.

Citron's foundation and update cycle rely heavily on Adrenaline. When Adrenaline updates to a newer Minecraft version or releases a patch for an existing one, you can, usually, expect Citron to have the same patch and update soon.

Of course, Citron has its own direction. While Adrenaline provides the foundation, Citron builds on it with its own selection of features, configurations, and quality-of-life improvements based on [its philosophy](my-philosophy.md).
