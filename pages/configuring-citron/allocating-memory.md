# Allocating Memory

{% hint style="info" %}
If Citron runs well with your launcher's default setting, you don't need to change memory allocation just because the option is there.
{% endhint %}

### Guide for RAM Allocation

Giving Minecraft more memory doesn't automatically improve performance. Too much can leave your OS and other applications short of memory.

| Allocation  | Amount |
| ----------- | -----: |
| Minimum     |   2 GB |
| Recommended |   4 GB |
| Maximum     |   6 GB |

For typical Citron use, allocating more than 4 GB is unlikely to make a noticeable difference.
