# Modrinth

You can download Citron from Modrinth and are free to choose the method you want but both require the ModrinthApp.

{% tabs %}
{% tab title="Using the app" %}
1. Download, install and launch the [Modrinth App](https://modrinth.com/app).
2. Under **Discover content**, search for **Citron**.
3. Click `+ Install` on the pack by _The Citron Modpack_.
   * To select a different Minecraft version, open the modpack page → `Versions` → ⬇️ on your chosen version.
4. Wait for the modpack to install.
5. Once installed, go to **Library** and hover over the Citron instance.
6. Click the ▶️ button to play.
{% endtab %}

{% tab title="Using the website" %}
1. Open the [Citron project page on Modrinth](https://modrinth.com/modpack/citron).
2. Open the **Versions** tab and find the version you want.
3. Click the download button (⬇️) to download the `.mrpack` file.
4. Open the Modrinth App and import the downloaded file as a new instance.
5. Once installed, find Citron in your library and click ▶️ to play.
{% endtab %}
{% endtabs %}
