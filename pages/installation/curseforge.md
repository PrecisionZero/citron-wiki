# CurseForge

You can download Citron from CurseForge and are free to choose the method you want but both require the CurseForge App.

{% tabs %}
{% tab title="Using the app" %}
1. Download and install the [CurseForge App](https://www.curseforge.com/download/app), then open it.
2. Select **Minecraft** from the sidebar or game list.
3. Search for **The Citron Modpack**.
4. Click **Install** and wait for the download to finish.
   * To install a different version, open the modpack's page → **Versions** → select the version you want.
5. Find Citron under **My Modpacks** and click **Play**.
6. If the Minecraft Launcher opens, click **Play** there as well.
{% endtab %}

{% tab title="Using the website" %}
1. Open the Citron project page on CurseForge.
2. Click **Install via App** and allow your browser to open CurseForge.
   * To choose a different version, open **Files**, select the version you want, and click **Install**.
3. Wait for CurseForge to finish installing Citron.
4. Open **My Modpacks** and click **Play** on Citron.
5. If the Minecraft Launcher opens, click **Play** there as well.
{% endtab %}
{% endtabs %}

{% endhint %}
