# First Launch

The first launch is best kept simple. Start Citron as installed before adding extra mods, shaders, or resourcepacks. That way, you'll know the base pack works before making changes.

{% stepper %}
{% step %}
## Launch Citron

Open your Citron instance from the launcher and launch it.
{% endstep %}

{% step %}
## Check the main menu

Citron uses a custom menu. If you need a button that isn't there, use **Default Menu** to switch to Minecraft's default menu, the missing button should be there.
{% endstep %}

{% step %}
## Play around and customise

Load up a world or join a server to see how Minecraft looks. If there's something you don't like, you're free to customise the game to your liking.

Check out our [customising.md](../customising.md "mention") guide if you need help.
{% endstep %}

{% step %}
## Configure Citron's instance

For some players, Citron works as it is. But this step is for those who want to change the instance and its configuration itself.

Open the settings for your Citron instance from the launcher and configure the instance settings to suit your computer.

We have a guide on this, check it out: [configuring-citron](../configuring-citron/ "mention").
{% endstep %}
{% endstepper %}

Once the game works, add shaders, resource packs, or extra mods few at a time. If something breaks, it'll be easier to find the cause.
