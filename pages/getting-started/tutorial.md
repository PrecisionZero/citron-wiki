# Tutorial

Already downloaded Citron? Here's the basic setup to get you into the game without messing around with extra settings first.

{% stepper %}
{% step %}
## Install Citron

Choose your launcher and follow the [Installation guide](../installation/). Make sure the build matches the Minecraft version you plan to play.
{% endstep %}

{% step %}
## Launch the instance

Open Citron from your launcher and wait for the main menu.&#x20;
{% endstep %}

{% step %}
## That's it

That's all, you're free to setup your keybinds and controls, configure mods, or play Minecraft as it is. We don't tell you what to do after the game launches.
{% endstep %}
{% endstepper %}

If something goes wrong, consult [Troubleshooting](../chatgpt-attempts-2/help/troubleshooting.md).
