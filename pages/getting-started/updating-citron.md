# Updating Citron

Before updating, back up your worlds and any configuration files you've changed. Then use the same launcher you used to install Citron.

{% tabs %}
{% tab title="Modrinth App" %}
1. Open the **Library** and select your Citron instance.
2. Click **Update pack** near the top of the instance page. It should be below **+ Install content**.
3. Select the Citron version you want. Choose the same Minecraft version or a newer one that Citron supports.
4. Click the update icon beside the version to update the existing instance. Don't click the version name itself; that can take you to a new installation instead.
5. Once the update finishes, launch Citron and check that your worlds and settings are still there.
{% endtab %}

{% tab title="CurseForge App" %}
CurseForge instructions will apply once Citron's own listing is available there.

1. Open **Minecraft → My Modpacks** and select Citron.
2. Open the profile menu and choose **Change Version**, if available.
3. Select a compatible Citron version that uses the same or a newer Minecraft version, then continue with the update.
4. Launch the profile when it finishes and check your worlds and settings.

If Citron isn't listed under the official project name, don't install a different pack with a similar name.
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
Do not downgrade an instance that contains worlds saved in a newer Minecraft version. If you want to try a development build or switch Minecraft versions, installing a separate instance is safer.
{% endhint %}

## After the update

Open the game and check your controls, video settings, and any custom configurations you rely on. Modpack defaults can change between builds, so restore your preferences if something was reset.

If the new build has a problem, try launching it without extra mods, shaders, or resource packs before troubleshooting further.

* [Backups and Uninstall](../backups.md) — keep a copy of your worlds and personal files.
* [Troubleshooting](../chatgpt-attempts-2/help/troubleshooting.md) — if the updated instance won't launch or behaves differently.
