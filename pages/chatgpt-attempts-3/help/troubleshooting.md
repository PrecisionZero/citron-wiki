# Troubleshooting

Start with the simplest checks. If you changed several settings or added multiple mods at once, test the pack without those changes before trying more fixes.

{% tabs %}
{% tab title="The game won't launch" %}
1. Check that the Citron file matches your Minecraft version and loader.
2. Restart the launcher and try again.
3. Temporarily remove any extra mods you've installed yourself.
4. Check the error message and game log for the first relevant error.
5. Make sure enough system memory is available.

If the base instance still fails, save the log and report the issue.
{% endtab %}

{% tab title="A menu option is missing" %}
1. Switch to **Default Menu**.
2. Check whether the option appears in Minecraft's default menu.
3. If the option is still missing, check the page for your exact Citron build and confirm that any relevant mod is present.
{% endtab %}

{% tab title="FPS is low or the game stutters" %}
1. Test without shaders and extra mods.
2. Lower render or simulation distance.
3. Close unnecessary background applications.
4. Compare the same world and settings before deciding an update caused a regression.
{% endtab %}

{% tab title="Resource packs or shaders look wrong" %}
1. Disable other packs and shaders.
2. Check version compatibility and any listed requirements.
3. Add your packs back one at a time to identify a conflict.
{% endtab %}
{% endtabs %}

## Still broken?

Record the exact Citron build ID, Minecraft version, what you were doing, and the error or crash log. Reproduce the problem on a clean instance if you can, then follow the **Report an Issue** guide.
