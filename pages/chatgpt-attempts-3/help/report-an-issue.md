# Report an Issue

Before reporting a problem, check Troubleshooting and see whether the same issue has already been reported. If possible, reproduce it on a clean Citron instance without extra mods, shaders, resource packs, or personal configuration changes.

## Include these details

* **Citron build ID:** Copy the exact identifier from the file or version page.
* **Minecraft version and loader:** Include both.
* **What happened:** Describe the problem briefly.
* **How to reproduce it:** List the steps that trigger it.
* **Logs or crash report:** Attach the relevant file or provide a link from a trusted log-hosting service.
* **Extra changes:** Mention any mods, shaders, resource packs, or configuration edits you added.

## Before submitting

1. Check for an existing report.
2. Test without personal additions.
3. Include the relevant log and screenshots only.
4. Remove account tokens or other private information from logs before sharing them.

<a href="https://github.com/PrecisionZero/citron/issues/new/choose" class="button primary" data-icon="github">Open the issue tracker</a>

A short report that can be reproduced is more useful than a long description without the details needed to investigate it.
