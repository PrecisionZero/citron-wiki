# FAQ

## Is Citron a performance-only modpack?

No. Citron combines performance improvements with quality-of-life and convenience features. If you want a pack focused more narrowly on performance, consider [Adrenaline](https://modrinth.com/modpack/adrenaline).

## Does a server need Citron installed?

Citron is designed for the client, so a server generally doesn't need it installed. Server rules still apply to individual mods and features.

## Why are some buttons missing from the main menu?

Citron has a custom menu. Switch to **Default Menu** to access buttons not shown there, including Language and Accessibility in the documented dev.8 build.

## Can I add my own mods?

Yes, but check the Minecraft version and Fabric compatibility, and add mods one at a time. Personal additions can introduce conflicts or duplicate features.

## How much RAM should I allocate?

If Citron runs well with the launcher's default setting, you don't need to change it. Around 4 GB is a reasonable manual starting point for typical use, but the right amount depends on your setup and extras.

## Why did a setting change after an update?

Mod and pack defaults can change between builds. Check your settings after updating and restore your personal preferences if needed.

## Where can I check supported versions?

Use the **Version Support** page and check the Minecraft version and loader listed for the exact file you intend to download.
