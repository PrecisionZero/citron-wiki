## How the catalogue works

* **Feature pages** keep the short description, provider, and version range.
* **Version pages** record what was added, changed, or removed in each build.
* **Provider changes** are documented on the same feature page, so the feature keeps its name even if its implementing mod changes.

For technical dependencies and libraries that do not create a distinct player-facing capability, see [Included Mods](included-mods.md).
