# Switchable Menus

Citron's menu includes a way to switch to Minecraft's default menu. This is important when you need an option or mod-added button that is not shown in the custom layout.

## How to use it

* In the Citron menu, select **Default Menu**.
* In Minecraft's default menu, select **Citron Menu** to return.

The exact appearance of these controls can change between builds.

## Implementation

This behaviour is part of Citron's custom menu configuration, recorded with the FancyMenu work.

## Version record

First recorded in **1.0.0-dev.7**.
