# Custom Main Menu

Citron uses a custom main menu to give the pack its own layout while keeping the game itself close to Vanilla.

## How it works

The layout and buttons changed during development. In the last build recorded here, buttons added by other mods appear on Minecraft's default menu, while the custom menu keeps its own button arrangement.

See [Main Menu and Options](main-menu-and-options.md) for the documented behaviour of the dev.8 menu.

## Provider

The feature was first recorded with **Simple Menu** in dev.4, then changed to a **FancyMenu**-based GUI in dev.5 and refined in later builds. Supporting projects recorded in the repository include [FancyMenu](https://modrinth.com/mod/fancymenu), [Konkrete](https://modrinth.com/mod/konkrete), and [Melody](https://modrinth.com/mod/melody).

## Version record

* **1.0.0-dev.4:** Simple Menu introduced.
* **1.0.0-dev.5:** Replaced by FancyMenu and supporting libraries.
* **1.0.0-dev.6 to dev.8:** Layout and button handling refined.
