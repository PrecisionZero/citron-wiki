# Menu Button Placement

Citron's custom menu does not try to display every button contributed by every installed mod. Keeping those buttons on Minecraft's default menu helps preserve the Citron layout.

## How to use it

If a button from another mod is missing, switch to **Default Menu** and look there before assuming the feature is unavailable.

## Implementation

This is a menu-layout decision rather than a standalone player feature supplied by one mod. It is implemented through the custom menu configuration.

## Version record

The development log records this behaviour in **1.0.0-dev.8**.
