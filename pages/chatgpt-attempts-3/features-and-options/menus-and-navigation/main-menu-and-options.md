# Main Menu and Options

Citron uses a custom main menu. It keeps the layout focused, but it does not show every button from Minecraft's default menu.

## Menu differences in the recorded dev.8 build

| Option                      | Citron menu              | Minecraft default menu |
| --------------------------- | ------------------------ | ---------------------- |
| Language                    | Not shown                | Available              |
| Accessibility               | Not shown                | Available              |
| Buttons added by other mods | Kept off the custom menu | Shown where supported  |
| Citron version note         | Shown                    | Hidden                 |
| Switch menus                | **Default Menu**         | **Citron Menu**        |

If a button is missing, switch to **Default Menu** before assuming the option is unavailable. Select **Citron Menu** in the default menu to return.
