# Shader Support

Shader support lets you use compatible shader packs to change lighting, shadows, and other rendering effects.

## How to use it

Check that your Citron build includes a compatible shader loader. If **Shader Packs** is available under **Options → Video Settings**, download a shader that supports your Minecraft version and hardware, then add it through the shader screen.

Shaders can affect performance significantly. Test them separately from other changes.

## Provider

The development record lists [Iris Shaders](https://modrinth.com/mod/iris) as the shader loader.

## Version record

First recorded in **1.0.0-dev.1**. Verify support in the exact build you use.
