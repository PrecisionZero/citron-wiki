# Connected Textures

Connected-texture support lets compatible resource packs join the appearance of neighbouring textures, such as matching glass edges. It only affects assets supported by the pack and renderer.

## How to use it

Install a resource pack that supports connected textures, then enable it in Minecraft's **Resource Packs** menu. If textures do not connect, check the pack's requirements and your Citron build.
