# Keybind Search

Keybind search lets you find a specific control without manually scrolling through every action.

## How to use it

Open **Options → Controls** and use the search field to find the action you want. You can then review or change its keybind.

## Provider

The development record associates this feature with [Controlling](https://modrinth.com/mod/controlling).
