# Inventory Controls

This feature adds mouse-based shortcuts for moving items around inventories, reducing repetitive clicks.

## How to use it

Open an inventory and try the supported mouse actions. Check the mod's documentation or in-game configuration for the exact gestures and keybinds in your version.

## Provider

The development record associates this feature with [Mouse Tweaks](https://modrinth.com/mod/mouse-tweaks).
