# Zoom

Zoom lets you inspect distant blocks and landmarks without changing your normal field of view.

## How to use it

Open **Options → Controls** and search for Zoom to see or change the keybind. The exact default can differ between mod versions.

## Provider

The development record associates this feature with [Zoomify](https://modrinth.com/mod/zoomify).

## Version record

First recorded in **1.0.0-dev.1**. Check the build you're using before assuming the feature is included.
