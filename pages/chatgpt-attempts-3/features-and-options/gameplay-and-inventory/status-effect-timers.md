# Status Effect Timers

Status effect timers show how much time remains on active effects, so you can judge when a potion or other effect will expire.

## Where to find it

Check the active effects display while playing. If the timer is not visible, check the installed build and the provider's configuration where available.

## Provider

The development record associates this feature with [Status Effect Timer](https://modrinth.com/mod/statuseffecttimer).
