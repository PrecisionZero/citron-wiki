# Food and Saturation Information

This feature adds extra information about hunger and saturation so you can make a more informed choice about food.

## Where to find it

AppleSkin can show food-related information in the HUD and in supported item tooltips. The exact indicators depend on the current configuration.

## Provider

The development record associates this feature with [AppleSkin](https://modrinth.com/mod/appleskin).

## Version record

First recorded in **1.0.0-dev.1**. Check the installed build if indicators are missing.
