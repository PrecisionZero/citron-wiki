# Main Menu and Options

Citron uses a custom main menu. It keeps the layout focused, but it does not display every button from Minecraft's default menu.

## Menu differences

| Option                      | Citron menu                       | Minecraft default menu |
| --------------------------- | --------------------------------- | ---------------------- |
| Language                    | Not shown in the documented build | Available              |
| Accessibility               | Not shown in the documented build | Available              |
| Buttons added by other mods | Kept off the custom menu          | Shown where supported  |
| Citron version note         | Shown                             | Hidden                 |
| Switch menus                | **Default Menu**                  | **Citron Menu**        |

If a button is missing, switch to **Default Menu** before assuming the option is unavailable. Use **Citron Menu** in the default menu to return.

## Settings after updates

Citron includes selected configurations and defaults. These can change between builds as mods are updated or settings are adjusted. After an update, check the controls and video settings you rely on.

{% hint style="info" %}
The table describes the recorded 1.0.0-dev.8+mc1.21.11.fabric development build. The menu may change in later builds.
{% endhint %}
