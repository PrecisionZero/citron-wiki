# Included Mods

Citron is organised around the features its mods provide, rather than treating a fixed mod count as the point of the pack. This page records projects mentioned in the development history.

{% hint style="warning" %}
This is a **development record, not a verified manifest of the latest downloadable build**. Mods can be added, removed, or updated. Check the actual file you're installing for its current contents.
{% endhint %}

## Recorded in the initial development build

| Area                          | Projects recorded                                                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Performance and rendering     | BadOptimizations, Clumps, Iris Shaders, Sodium Extra, Stfu                                                                           |
| Quality of life and interface | AppleSkin, BactroMod, Better Tab, BetterF3, Controlling, Durability Plus, Searchables, Shulker Box Tooltip, uku's Armor HUD, Zoomify |
| Resource packs and visuals    | Continuity                                                                                                                           |
| Libraries and configuration   | ukulib, YetAnotherConfigLib (YACL)                                                                                                   |

Where available, project pages include [AppleSkin](https://modrinth.com/mod/appleskin), [BactroMod](https://modrinth.com/mod/bactromod), [BetterF3](https://modrinth.com/mod/betterf3), [Continuity](https://modrinth.com/mod/continuity), [Iris](https://modrinth.com/mod/iris), [Sodium Extra](https://modrinth.com/mod/sodium-extra), [Zoomify](https://modrinth.com/mod/zoomify), and [Shulker Box Tooltip](https://modrinth.com/mod/shulkerboxtooltip).

## Later changes recorded

* **dev.2:** Status Effect Timer.
* **dev.3:** Mouse Tweaks and LambDynamicLights.
* **dev.4:** Simple Menu was added for the main menu.
* **dev.5:** Simple Menu was removed; FancyMenu, Konkrete, and Melody were added for the custom menu.

See the [development stages file](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md) for the source record. Third-party projects remain under their own licences.
