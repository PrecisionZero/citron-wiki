# Performance Foundation

Citron builds on Adrenaline's performance-focused foundation and adds selected projects for its own feature set. Performance is the combined result of the pack, game version, world, settings, and hardware; it is not a guarantee of a particular FPS.

## What this means

* Performance-related projects work together rather than providing one user-visible feature each.
* Quality-of-life features and visual extras can affect performance depending on how they are used.
* Results should be compared on the same hardware and settings.

## Foundation

Citron is based on [Adrenaline](https://modrinth.com/modpack/adrenaline). Other performance-related projects are part of a build's implementation and can change over time.

## Version record

The development log records the initial performance foundation in **1.0.0-dev.1**. See **Performance Tips** for troubleshooting and the repository's testing records for measured results.
