# Debug Screen Layout

The debug screen shows technical information about the game. This feature changes its layout to make the information easier to scan.

## How to use it

Press F3 to open the debug screen. If you need to adjust what is displayed, check the provider's configuration options for the installed build.

## Provider

The development record associates this feature with [BetterF3](https://modrinth.com/mod/betterf3).
