# Version Support

Citron builds target a specific Minecraft version and mod loader. Check these details on the exact file you plan to download; don't assume a newer Citron build automatically supports a newer Minecraft release.

The repository currently records `1.0.0-dev.8+mc1.21.11.fabric` as a development build for **Minecraft 1.21.11 with Fabric**. This is not a guarantee that future builds will target the same version.

## Before installing

* Check the Minecraft version shown on the file.
* Confirm the loader is Fabric where required.
* Check that any extra mods support the same Minecraft version and loader.
* For multiplayer, use a Minecraft version supported by the server.

## Understanding the build ID

| Part        | Meaning                  |
| ----------- | ------------------------ |
| `1.0.0`     | Intended release version |
| `dev.8`     | Development build number |
| `mc1.21.11` | Target Minecraft version |
| `fabric`    | Mod loader               |

Use [Version History](version-history/) to review the changes recorded for each build. Each build page links to the feature guides for its additions and changes.

For original identifiers and source records, see the [Citron development stages](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md).
