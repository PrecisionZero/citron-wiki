## Recording future versions

For each new recorded build:

1. Add one version page listing only features that were added, changed, or removed.
2. Update the affected feature pages' version ranges and provider details.
3. If a feature stays the same but its provider changes, update that feature page rather than creating a duplicate.
4. Keep libraries and technical dependencies in [Included Mods](../../features-and-options/included-mods.md).

The ranges in the feature catalogue reflect this documented development history through `dev.8`, not a guarantee about newer downloadable builds. See the [development stages file](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md) for the original notes.
