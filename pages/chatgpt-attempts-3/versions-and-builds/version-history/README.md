## Documenting a new release

For every new release or published version:

1. Add a child page for that exact version under this section.
2. List the player-facing features added, changed, or removed. Link each feature to its existing guide and record the provider or implementation.
3. If a feature stays the same but its provider changes, update the existing feature page instead of creating a duplicate feature.
4. Add the new version to each affected feature page's **Recorded builds** list.
5. Keep library-only and technical changes in implementation notes or [Included Mods](../../features-and-options/included-mods.md), rather than treating every mod as a separate feature.

For original build IDs and implementation notes, see the [development stages file](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md).
