# 1.0.0-dev.8

**Minecraft:** 1.21.11\
**Loader:** Fabric\
**Status:** Development build

## Features changed

| Feature / guide                                                                                   | Change                                                                                                                                                | Provider / implementation                                            |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| [Custom Main Menu](../../features-and-options/menus-and-navigation/custom-main-menu.md)           | Changed from a title-screen implementation to a GUI.                                                                                                  | FancyMenu, with Konkrete and Melody recorded as supporting libraries |
| [Switchable Menus](../../features-and-options/menus-and-navigation/switchable-menus.md)           | Kept the menu-switching controls so users can reach the default menu.                                                                                 | Citron menu configuration using FancyMenu                            |
| [Menu Button Placement](../../features-and-options/menus-and-navigation/menu-button-placement.md) | Buttons added by other mods now appear on Minecraft's default menu instead of the Citron menu.                                                        | Citron menu configuration using FancyMenu                            |
| [Main Menu and Options](../../features-and-options/menus-and-navigation/main-menu-and-options.md) | Language and Accessibility are no longer shown on the Citron menu. The version note remains on the Citron menu but was removed from the default menu. | Citron menu configuration                                            |

The behaviour described here reflects the recorded dev.8 build. Check the menu guides for the details and use the [development stages file](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md) for the original notes.
