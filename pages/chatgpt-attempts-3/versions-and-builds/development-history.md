# Development History

The following summary is based on Citron's development log. These are development builds, not a list of final public releases.

| Build       | Main recorded change                                                                                                                 |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 1.0.0-dev.1 | Established the initial group of performance and quality-of-life mods.                                                               |
| 1.0.0-dev.2 | Added Status Effect Timer.                                                                                                           |
| 1.0.0-dev.3 | Added Mouse Tweaks and LambDynamicLights.                                                                                            |
| 1.0.0-dev.4 | Introduced Simple Menu for the main menu.                                                                                            |
| 1.0.0-dev.5 | Replaced Simple Menu with FancyMenu and added its supporting libraries.                                                              |
| 1.0.0-dev.6 | Continued menu work and added an Extra Mods button.                                                                                  |
| 1.0.0-dev.7 | Added switching between Citron's menu and Minecraft's default menu.                                                                  |
| 1.0.0-dev.8 | Refined the FancyMenu GUI, moved mod-added buttons to the default menu, and removed Language and Accessibility from the Citron menu. |

All builds listed above target Minecraft 1.21.11 with Fabric in the development record.

For original build IDs and further details, see the [full development stages file](https://github.com/PrecisionZero/citron/blob/main/Developer/Development_stage.md). The log records development work and does not guarantee that every listed mod remains in the latest downloadable file.
