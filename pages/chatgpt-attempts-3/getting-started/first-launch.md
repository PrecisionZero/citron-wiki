# First Launch

Start Citron as installed before adding extra mods, shaders, or resource packs. This confirms that the base instance works and gives you a clean setup to return to if something breaks later.

{% stepper %}
{% step %}
## Launch Citron

Open the instance from your launcher and wait for the main menu. The first launch may take longer while files and caches are prepared.
{% endstep %}

{% step %}
## Check the menu

Citron uses a custom main menu. If a button or option is missing, switch to **Default Menu** to open Minecraft's default menu.
{% endstep %}

{% step %}
## Test the game

Open a single-player world or join a server you normally use. Check that the game launches and the main features you rely on work.
{% endstep %}

{% step %}
## Customise only when needed

If everything works, start playing. Change settings or add content only when you have a reason to; you don't need to configure every mod just because it's included.
{% endstep %}
{% endstepper %}

After the base pack is working, add any extra mods, resource packs, or shaders one at a time.
