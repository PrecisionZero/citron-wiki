# Backups and Uninstall

Before updating Minecraft, changing instances, or uninstalling Citron, copy important files to a location **outside the instance folder**. A backup stored inside an instance can be deleted along with it.

## What to back up

| File or folder | What it contains                   |
| -------------- | ---------------------------------- |
| saves          | Single-player worlds               |
| screenshots    | Screenshots                        |
| resourcepacks  | Resource packs you've added        |
| shaderpacks    | Shader packs you've added          |
| servers.dat    | Saved multiplayer server list      |
| options.txt    | Video options and keybinds         |
| config         | Personal mod configuration changes |

You may also want to keep any mods you installed yourself. Don't copy the entire old mods folder into a new instance without checking version compatibility.

## Back up your instance

1. Open Citron in your launcher.
2. Use the instance menu to open its folder.
3. Copy the files and folders you want to keep to Documents, an external drive, or another safe location.
4. Check that the copied files exist before deleting the instance.

## Uninstall Citron

Use the launcher to remove the Citron instance or profile. Read the confirmation carefully, because the launcher may delete the instance files along with it.

Uninstalling the instance does not remove your separate backups. Keep them until you've confirmed you no longer need them.

## Restoring files

Install a fresh Citron instance and launch it once. Close the game, then copy your worlds and personal files into the new instance. Restore configuration files selectively instead of replacing every file with an old copy.
