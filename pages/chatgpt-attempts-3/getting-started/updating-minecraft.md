# Updating Minecraft

Changing the Minecraft version is different from updating Citron within the same version. Mods, configs, and worlds may not behave the same way across game versions.

## Recommended method

1. Back up your worlds and personal files.
2. Check the [Citron project page](https://modrinth.com/modpack/citron) for a build that explicitly supports the Minecraft version you want.
3. Install that build as a **new instance** rather than forcing the current instance to use a different Minecraft version.
4. Launch the new instance once before copying anything into it.
5. Copy your worlds and personal files from the backup, then test the game.

{% hint style="warning" %}
A world saved in a newer Minecraft version may not work in an older one. Make a separate backup before opening a world in a different game version.
{% endhint %}

## What should I copy?

Copy only the files you need, such as your saves folder, screenshots, resource packs, shader packs, or server list. Restore configuration files selectively; old settings may not work with newer versions of mods.

Keep the previous instance until you've checked that the new one works.
