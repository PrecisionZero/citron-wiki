# Installation

The Modrinth App is the simplest way to install Citron and keep the instance organised.

{% tabs %}
{% tab title="Using the Modrinth App" %}
{% stepper %}
{% step %}
## Install the launcher

Download and install the [Modrinth App](https://modrinth.com/app), then open it.
{% endstep %}

{% step %}
## Find Citron

Under **Discover content**, search for **Citron** and open the project by **The Citron Modpack**.
{% endstep %}

{% step %}
## Choose a version

Click **Install**. If you need a specific Minecraft version, open the project's **Versions** tab and select a compatible file.
{% endstep %}

{% step %}
## Launch the instance

Wait for installation to finish, open **Library**, find Citron, and click the play button.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Using a downloaded .mrpack" %}
1. Open the [Citron project page](https://modrinth.com/modpack/citron).
2. Open **Versions** and download the .mrpack file you need.
3. Open the Modrinth App and use its import option to import the downloaded file.
4. Wait for the instance to be created, then launch it from **Library**.
{% endtab %}
{% endtabs %}

## Before you launch

* Check that the file targets the Minecraft version you want to play.
* Keep the original instance until the new one launches successfully.
* Download Citron from its official project page. Avoid reuploads from unknown sources.

Citron is still in development, so its supported Minecraft versions and features can change between builds.
