# Updating Citron

Use this guide when a newer Citron build is available for the **same Minecraft version and loader** as your current instance.

{% hint style="warning" %}
Back up your worlds and any configuration files you changed before updating. A newer build can update mods or change default settings.
{% endhint %}

1. Open the official [Citron project page on Modrinth](https://modrinth.com/modpack/citron).
2. Check the available versions and choose a build for the Minecraft version you're already using.
3. Use your launcher to update the existing instance or install that build as a separate instance, depending on the options it provides.
4. Launch the updated instance and check your worlds, controls, video settings, and important configurations.
5. If the new build has a problem, test it without any extra mods, shaders, or resource packs you installed yourself.

## Which release should I use?

Citron's development builds can contain unfinished changes. If a stable release is available, it is generally the better choice for a regular playthrough. If only development builds are available, read the version information and keep a separate backup.

Do not delete your previous instance until the new one works and your important files are safe.
