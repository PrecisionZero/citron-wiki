# Adding and Removing Mods

You can add mods to Citron, but every addition can introduce conflicts, duplicate a feature, or change performance. Check compatibility before installing anything.

## Adding a mod

1. Check the mod supports the same Minecraft version and Fabric loader as your Citron build.
2. Check whether Citron already includes the feature you need.
3. Back up the instance before making larger changes.
4. Install one mod at a time through your launcher's content manager, or place a compatible .jar in the **mods folder for the Citron instance**.
5. Launch the game and test the new mod before adding another.

Use trusted sources such as [Modrinth](https://modrinth.com/mods). Follow the mod's own installation instructions if it requires a dependency.

## Removing a mod

If you added the mod yourself, disable or remove that mod first and test whether the problem disappears. Prefer the launcher's content controls when available.

{% hint style="warning" %}
Be careful when removing mods that came with Citron. Some provide features you use; others are libraries or dependencies required by another mod. Removing them can stop the game from launching.
{% endhint %}

If you have changed several things and can't work out the cause, install a fresh Citron instance and test there. Keep your original instance and backups until you're sure you no longer need them.
