# Compatibility and Servers

Citron is designed to run on the player's client, so a multiplayer server generally does not need Citron installed. That does not guarantee every server allows every mod or feature included in the pack.

## Before joining a server

* Check the server's rules about client-side mods and gameplay advantages.
* Ask the server staff if you're unsure whether a particular feature is allowed.
* Make sure your Minecraft version matches the server's supported version.

Server rules differ. Staff have the final say on what is permitted, even if the same mod is accepted elsewhere.

## If you can't join

First check the Minecraft version. If it matches, try joining with a clean Citron instance and without any extra mods you've added. Check the error message before changing files.

A client-side pack can still contain a mod or feature that a server restricts. Only use features permitted by the server's rules.
