# Settings and Memory

Citron is intended to work without extensive setup. Change a setting when you have a reason to, and make a note of what you changed so you can undo it if necessary.

## Basic settings

* **Controls:** Open Options → Controls to change keybinds. Use the search field if you can't find an action.
* **Video:** Adjust render distance, simulation distance, particles, and other settings to suit your hardware.
* **Mod settings:** Some mods add their own configuration screens. Their locations depend on the mod and the Citron build.
* **Menu options:** If Language, Accessibility, or another button isn't available in Citron's menu, switch to **Default Menu**.

## Memory allocation

More allocated RAM does not automatically mean better performance. The operating system and other applications still need memory.

* If Citron launches and plays normally using the launcher's default allocation, leave it alone.
* If you need to set it manually, **4 GB is a reasonable starting point** for typical use.
* Consider a little more only if you see memory-related errors or use especially demanding extras.
* Don't allocate all your computer's RAM to Minecraft.

The right amount depends on your hardware, the world, and any shaders or extra mods you use. Changing memory allocation will not fix every kind of stutter or low FPS.

## After changing settings

Change one or two things at a time, test the game, and keep track of what helped. If a change makes things worse, restore the previous value before trying another adjustment.
