# Performance Tips

Citron includes performance improvements, but results still depend on your CPU, GPU, memory, settings, world, and any extras you've installed.

## Start with these checks

* **Render distance:** Lower it if terrain is slow to draw or your FPS drops in large areas.
* **Simulation distance:** Reduce it if the CPU struggles with entities and world activity.
* **Shaders:** Disable shaders while testing baseline performance.
* **Extra mods:** Temporarily remove your own additions to check whether they cause a conflict.
* **Background apps:** Close applications you don't need while playing.
* **Memory:** More RAM isn't always better. Leave enough for Windows and other applications.

## Compare fairly

Use the same world, Minecraft version, render distance, and video settings. Let the world load before comparing results, and repeat the test. A single FPS reading is not enough to prove one build is faster than another.

If a problem started after an update, test the new build in a clean instance with similar settings before changing lots of options. That makes it easier to identify what caused the difference.

If performance is still poor, record your hardware, Citron build ID, settings, and whether shaders or extra mods are enabled before reporting it.
