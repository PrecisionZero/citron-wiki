# Foundation

## Thank you, Adrenaline

Citron is built on [Adrenaline](https://modrinth.com/modpack/adrenaline), which provides the performance foundation for the project. Credit to the Adrenaline team for the work that made this starting point possible.

Citron has a different focus. It keeps performance as a foundation and builds on it with selected quality-of-life features, configurations, and its own interface.

## Update approach

Citron's development and update cycle relies on changes in the Adrenaline foundation. When Adrenaline supports a newer Minecraft version or receives a patch for an existing one, Citron may follow after the changes and compatibility have been checked.

That does not mean every update is automatic or immediate. Citron's own features and configurations also need to be checked.

The aim isn't to reinvent the wheel. It's to build a more convenient experience on a solid base without making players set everything up themselves.
