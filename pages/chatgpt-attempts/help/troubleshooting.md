# Troubleshooting

Try these steps before reporting a problem. The exact cause may depend on your Citron build, launcher, Minecraft version, and any personal modifications.

## The game will not launch

1. Check that you installed the correct Citron file for the intended Minecraft version.
2. Update or restart your launcher.
3. If you added mods, test a clean Citron instance without them.
4. Check the launcher's error message and game log for the first relevant error.

## The game crashes after adding a mod

Remove the most recently added mod and test again. Confirm that the mod supports the same Minecraft version and loader as your instance and that its dependencies are installed.

## A feature or setting is missing

Check the documentation for your exact Citron version. Features and configuration options may change between builds. If the option should be present, test with the original configuration.

## The game runs poorly

Test without shaders or extra mods, lower demanding video settings, and close unnecessary background applications. Performance varies by hardware and world.

If the issue continues, follow [Report an Issue](report-an-issue.md).
