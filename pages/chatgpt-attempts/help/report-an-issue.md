# Report an Issue

Before reporting a problem, check the relevant version notes and try the troubleshooting steps. If possible, reproduce the issue with a clean Citron instance without extra mods or custom configurations.

## Include these details

* Citron version and build ID.
* Minecraft version and mod loader.
* Launcher used.
* What you expected to happen and what actually happened.
* Steps to reproduce the issue.
* The relevant game log, crash report, or screenshot.

## Where to report it

Use the official issue tracker or support channel linked from the Citron project page. Do not upload private account information or unrelated personal files. A clear, reproducible report makes it easier to investigate the problem.
