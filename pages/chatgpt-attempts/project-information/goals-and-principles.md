# Goals and Principles

Citron is built around performance, convenience, and useful quality-of-life features. The aim is to make Minecraft more comfortable to play without turning it into a different game.

## Integrated Utility

The everyday features players commonly search for should already be included and configured to work together. Citron aims to reduce the need to find individual mods, install them, and work out their settings one by one.

## Features over Mods

Mods are implementation details that can change. Citron evaluates the feature a mod provides rather than keeping a mod simply because it is popular or already included. If another option provides the same benefit more reliably or with less unnecessary complexity, it may be a better fit.

## Performance is one part of the experience

Citron includes performance optimisations, but it is not designed to be the most minimal performance-only pack. It is aimed at players with reasonably capable hardware who want a useful set of conveniences alongside performance improvements.

## Stay close to Vanilla

Additions should complement the normal Minecraft experience rather than replace it with a different style of gameplay. If a feature adds complexity without enough value, it is likely unnecessary for Citron.
