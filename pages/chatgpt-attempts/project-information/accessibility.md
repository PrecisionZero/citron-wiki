# Accessibility

Citron's custom main menu does not display Minecraft's **Accessibility** or **Language** buttons in the documented development build. You can switch to Minecraft's default menu using the **Default Menu** option to access those buttons.

Minecraft's accessibility options may include controls for text display, narration, visual effects, and other interface preferences. The exact options depend on your Minecraft version.

If you rely on an accessibility setting, check it after installing or updating Citron. Keep in mind that the custom menu can change between development builds; report any missing or inaccessible control with your Citron build ID and the steps needed to reproduce the issue.
