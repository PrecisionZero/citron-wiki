# Version Support

Citron's development records currently identify `1.0.0-dev.8+mc1.21.11.fabric` as the development build, targeting Minecraft `1.21.11` with Fabric. This is a development build, not a guarantee that every future Citron release will support the same Minecraft version.

## Choosing a version

* Check the Minecraft version and loader listed for the exact Citron file you download.
* Install a build that matches the version you want to play.
* Do not assume that a newer Minecraft release is supported until Citron publishes a compatible build.
* Features and configurations may change between development builds.

## Development build IDs

Citron uses version identifiers in the form `1.0.0-dev.N+mcVERSION.fabric`. The `dev.N` number advances with each development build; the Minecraft version and loader are recorded in the build metadata. Original build identifiers are retained in development records for traceability.

For the changes made in each build, see [Citron Versions](../../getting-started/versions/index.md). Use the official Citron project listing as the source of truth for downloadable versions.
