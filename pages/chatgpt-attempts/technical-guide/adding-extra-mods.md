# Adding Extra Mods

Citron is curated and tested as a set. Adding mods can be useful for personal customisation, but it changes the setup from the one Citron's developers tested.

## Before adding a mod

1. Check that it supports the same Minecraft version and mod loader as your Citron instance.
2. Read its requirements and install any dependencies it needs.
3. Check for conflicts with features already provided by Citron.
4. Back up your instance before making changes.

Add one mod at a time and launch the game after each change. If a problem appears, remove the most recent addition and test again. Do not assume that a mod compatible with another modpack is automatically compatible with every Citron build.
