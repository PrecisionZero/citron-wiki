# Compatibility and Servers

Citron is designed as a client-side modpack. A server generally does not need Citron installed for you to connect, but that does not mean every server permits every included mod or feature.

## Playing on servers

* Read the server's rules about client-side mods and gameplay advantages.
* Ask server staff if a mod or feature is not clearly covered by the rules.
* Remember that server staff make the final decision about what is allowed.

## Adding other mods

Compatibility depends on the exact Citron build, Minecraft version, loader, and other mods installed. A mod that works with another pack is not automatically compatible with Citron.

If you encounter a problem, reproduce it with a clean Citron instance before reporting it. See the existing [Disclaimers](../../index/disclaimers.md) for the project's full guidance.
