# Configurations and Settings

Citron ships with selected configurations intended to make the included mods work well together. These defaults may change between builds as mods and compatibility requirements change.

You can adjust settings to suit your preferences, but changing configurations may affect performance, visuals, or compatibility. If you are troubleshooting a problem, first test with the original Citron settings.

Before updating, keep a copy of important personal configuration changes. After an update, check settings you rely on and restore them if they were reset or changed.

When documenting a particular option, include the menu or configuration file where it can be found, the default value for the relevant Citron version, and what changing it does. Do not assume the same setting exists in every version.
