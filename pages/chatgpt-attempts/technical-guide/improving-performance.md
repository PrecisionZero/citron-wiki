# Improving Performance

Citron already includes performance improvements, but your settings and hardware still affect how smoothly Minecraft runs. Try these changes one at a time so you can tell which one helps.

## Start with the basics

* Close applications you do not need while playing.
* Make sure your laptop or desktop is not overheating or running in a restricted power mode.
* Lower render distance if the game struggles while loading or drawing distant terrain.
* Lower simulation distance if the world is demanding on the CPU.
* Disable shaders while testing performance.
* Temporarily remove extra mods and resource packs to check whether they are contributing to the problem.

## Test fairly

Compare performance in the same world, with the same Minecraft version, render distance, and video settings. Let the world settle before recording results and repeat the test rather than relying on a single moment.

## Memory allocation

Giving Minecraft more memory does not automatically improve performance. Too much allocation can leave less memory for Windows and other applications. Start with the launcher's default or Citron's documented recommendation unless you have evidence that the game is running out of memory.

If performance remains poor, note your hardware, Citron build, settings, and whether the issue occurs in a clean instance before reporting it.
