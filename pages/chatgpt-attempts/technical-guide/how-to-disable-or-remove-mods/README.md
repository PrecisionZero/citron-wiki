# How to Disable or Remove Mods

Removing a bundled mod can break features or stop Citron from launching. If you are troubleshooting, first test a clean instance and change one thing at a time.

Choose your launcher:

* [Modrinth App — Disabling Mods](modrinth-app-disabling-mods.md)
* [CurseForge App — Disabling Mods](curseforge-app-disabling-mods.md)

## Before removing a mod

* Back up your instance.
* Check whether other mods depend on it.
* Do not remove libraries or dependencies just because their purpose is unclear.
* Keep track of changes so you can restore the original setup.

If you want to return to Citron's tested configuration, installing a fresh instance is often easier than reconstructing which files were removed.
