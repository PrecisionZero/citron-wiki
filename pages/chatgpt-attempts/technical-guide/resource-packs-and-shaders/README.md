# Resource Packs and Shaders

Resource packs and shaders can change how Minecraft looks, but compatibility depends on the Minecraft version, rendering mods, and the files you add. Check the feature list for your Citron build before assuming a particular shader loader is included.

* [How to Add Shaders](how-to-add-shaders.md) — install and troubleshoot shader packs.
* [Resource Pack Troubleshooting](resource-pack-troubleshooting.md) — fix packs that fail to load or display incorrectly.

## Resource packs

1. Download a resource pack that supports your Minecraft version.
2. Open **Options → Resource Packs** in Minecraft.
3. Use **Open Pack Folder** if available and place the resource-pack file in that folder.
4. Return to the game and enable the pack.

If multiple packs change the same textures, their order affects which textures appear. Disable other packs while troubleshooting.

## Shaders

Before installing a shader pack, confirm that your Citron build includes a compatible shader loader. Use shader packs that support your Minecraft version and graphics setup. If you encounter crashes or rendering issues, disable the shader and test Citron without other additions.
