# CurseForge App — Adding Mods

1. Open CurseForge and select **Minecraft**.
2. Open **My Modpacks** and choose your Citron profile.
3. Select **Add More Content** or the equivalent content-browsing option.
4. Search for the mod you want.
5. Check that it supports Fabric and the Minecraft version of your Citron profile, then install it.
6. Launch the profile and test the change before adding more mods.

> Extra mods can cause crashes, conflicts, or unexpected behaviour. Back up your instance before making significant changes, and check dependencies listed by the mod author.

Only install files from sources you trust. A mod for another Minecraft version or loader may not work with Citron.
