# Modrinth App — Adding Mods

1. Open Modrinth and go to **Library**.
2. Select your Citron instance and open its content list.
3. Use the content browser to find the mod you want.
4. Check that it supports Fabric and the Minecraft version used by your Citron instance, then install it.
5. Launch the game and test the new mod before adding anything else.

> Adding mods changes the setup Citron was tested with. Some mods conflict with existing features or require extra dependencies. Avoid changing the instance's modpack association, as this may affect future updates.

If the mod is not available through the app's content browser, follow the mod developer's instructions and make sure the file goes into the correct instance.
