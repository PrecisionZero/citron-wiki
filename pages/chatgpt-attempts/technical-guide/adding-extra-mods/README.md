# Adding Extra Mods

Citron is tested as a curated set of mods and configurations. You can customise your instance, but extra mods may introduce conflicts, change performance, or duplicate features already provided by Citron.

Choose your launcher:

* [Modrinth App — Adding Mods](modrinth-app-adding-mods.md)
* [CurseForge App — Adding Mods](curseforge-app-adding-mods.md)

## Before installing a mod

* Check that it supports the same Minecraft version and Fabric loader as your Citron build.
* Read the dependencies and installation instructions from the mod author.
* Check whether Citron already provides the feature.
* Back up the instance before making significant changes.

Install one mod at a time and test the game before adding another. If something breaks, remove the last addition and retest.
