# Resetting Settings

If a setting causes problems or an update changes your configuration, the safest first step is to restore the affected setting to its default. The exact reset controls depend on the mod and Citron build.

## Before resetting

1. Close Minecraft.
2. Back up any configuration files you have edited manually.
3. Identify whether the setting belongs to Minecraft, Citron's menu, or a specific mod.

## Reset a setting

* If the mod has an in-game configuration screen, look for a reset or restore-defaults option.
* If the setting is a normal Minecraft option, change it back in the relevant settings menu.
* If the problem started after editing a config file, restore the backed-up file or regenerate the affected config only after checking what settings it contains.

Do not delete the entire `config` folder as a first step. That can reset unrelated settings and make it harder to identify the cause.

## After a Citron update

Check the relevant version page for documented configuration changes. Citron's default settings may change to improve compatibility or reliability, so reapply personal preferences only after confirming the updated instance works.
