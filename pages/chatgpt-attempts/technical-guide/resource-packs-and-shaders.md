# Resource Packs and Shaders

You can customise Minecraft's appearance with resource packs, and some setups can also use shaders. Compatibility depends on the Citron build, Minecraft version, and the extra components required by the pack you want to use.

## Resource packs

1. Download a resource pack that supports your Minecraft version.
2. Open Minecraft's **Options → Resource Packs** menu.
3. Use **Open Pack Folder** if available, then place the downloaded resource-pack file in that folder.
4. Return to the game and enable the pack.

If the pack changes textures that Citron or another resource pack also changes, the order of resource packs may affect which textures appear.

## Shaders

Before installing a shader pack, check whether your Citron version includes or supports a compatible shader loader. Do not assume every Citron build has shader support enabled by default.

Use shader packs that support your Minecraft version and graphics setup. If you experience crashes or rendering issues, disable the shader first and test Citron without other added modifications.

## Troubleshooting

If a visual issue only appears after adding a resource pack or shader, disable that addition to check whether it is the cause. See [Troubleshooting](../help/troubleshooting.md) if the issue remains.
