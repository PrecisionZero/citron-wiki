# Supported Versions

Citron's supported Minecraft versions can change as its foundation, dependencies, and included mods are updated. Use the official Citron project listing and the [version index](../../getting-started/versions/index.md) as the source of truth for currently available builds.

Before installing, check the Minecraft version and loader shown for the specific file you choose. Do not assume that a development build supports the same versions as a later release.

If a version is not listed on the official project page, treat it as unsupported unless the Citron project explicitly announces otherwise.
