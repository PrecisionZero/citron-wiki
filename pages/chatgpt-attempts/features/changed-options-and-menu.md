# Changed Options and Menu

Citron uses a custom main menu. It keeps the layout focused, but not every button from Minecraft's default menu appears there.

## Citron menu

The development notes for build `1.0.0-dev.8+mc1.21.11.fabric` document these changes:

* The Citron menu is a GUI created with FancyMenu.
* The **Language** and **Accessibility** buttons are not shown on the Citron menu.
* Buttons added by other mods appear on Minecraft's default menu instead of the Citron menu.
* The **Default Menu** option lets you switch to Minecraft's default menu; the default menu also has an option to return to the Citron menu.
* The Citron version note appears on the Citron menu, not on the default menu.

If you need a button that is missing from the Citron menu, switch to the default menu. This list describes the documented development build and may change in later versions.

## Configuration changes

Citron also ships with selected mod configurations. These can change between builds, so check the relevant version page for documented changes. Restore personal preferences if an update changes or resets a setting.
