# Features

Citron combines performance improvements with useful features that make everyday Minecraft more convenient. The goal is not to include the largest possible number of mods; each addition should provide a clear benefit.

* Feature Index — browse the documented player-facing features and the mods that provide them.
* [Performance](performance/) — what performance improvements can and cannot promise.
* [Quality of Life](quality-of-life.md) — how Citron evaluates convenience features.
* [Visuals and Interface](visuals-and-interface.md) — menus and presentation changes.
* [Changed Options and Menu](changed-options-and-menu.md) — current documented custom-menu behaviour.

The included feature set can change between builds. Use the version pages to check what changed in a specific release.
