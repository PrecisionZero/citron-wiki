# Feature Index

This page is the starting point for discovering what Citron offers. Citron focuses on performance, quality of life, and convenience while keeping the experience close to Vanilla Minecraft.

Feature pages should describe the player-facing result, explain any important limitations, and identify the mod that provides it. The included mods can change between releases, so check the relevant [Citron version](../../getting-started/versions/index.md) for what is included in a specific build.

## Categories

* [Performance](performance.md) — improvements intended to help Minecraft run more smoothly.
* [Quality of Life](quality-of-life.md) — practical conveniences that reduce friction during normal play.
* [Visuals and Interface](visuals-and-interface.md) — changes to presentation and the user interface.

Add individual feature entries only after confirming that the feature is included in a published Citron build.
