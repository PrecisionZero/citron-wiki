# Performance

Citron includes performance improvements, but it is not a performance-only pack. It also includes quality-of-life features and selected configurations.

The initial development records list performance-related mods including **BadOptimizations** and **Clumps**, alongside Sodium-based rendering through Citron's Adrenaline foundation. This is not a promise that every mod or configuration remains unchanged in every build.

## What to expect

Actual results depend on hardware, Minecraft version, world, video settings, and other software running on your computer. Citron cannot guarantee a specific FPS or eliminate every stutter.

* [Performance Expectations](performance-expectations.md) — understand why results vary and how to compare builds fairly.
* Improving Performance — practical adjustments when the game runs poorly.

## Compare performance fairly

Use the same world, Minecraft version, render distance, and video settings. Test without shaders or extra mods first, let the world load before measuring, and repeat the test. Note your hardware and whether the issue happens in a clean Citron instance.

For a particular build, refer to [Citron Versions](../../../getting-started-1/versions/index.md).
