# Feature Index

Citron focuses on performance, useful quality-of-life features, and a cleaner day-to-day experience without changing what makes Minecraft Minecraft. The feature set can change between development builds, so check the version notes for the build you use.

## Quality of life

* [Zoom](zoom.md) — zoom in on distant details. **Mod:** Zoomify
* [Shulker Box Tooltips](shulker-box-tooltips.md) — inspect shulker-box contents from the tooltip. **Mod:** Shulker Box Tooltip
* [Food and Saturation Information](food-and-saturation-information.md) — see extra hunger and saturation information. **Mod:** AppleSkin
* [Durability Tooltips](durability-tooltips.md) — view item durability in a tooltip. **Mod:** Durability Plus
* [Status Effect Timers](status-effect-timers.md) — see how much time remains on active effects. **Mod:** Status Effect Timer
* [Mouse Tweaks](mouse-tweaks.md) — make inventory handling more convenient. **Mod:** Mouse Tweaks
* [Dynamic Lights](dynamic-lights.md) — dynamic lighting from supported items and entities. **Mod:** LambDynamicLights
* [Inventory and Control Convenience](inventory-and-control-convenience.md) — search keybinds and improve inventory interaction. **Mods:** Controlling, Mouse Tweaks
* [Visual Comfort Options](visual-comfort-options.md) — visual options for brightness, fog, overlays, and first-person rendering. **Mod:** BactroMod

## Interface and information

* [Improved Debug Information](improved-debug-information.md) — reorganise the debug screen. **Mod:** BetterF3
* [Player List Improvements](player-list-improvements.md) — scroll the player list and view numerical ping. **Mod:** Better Tab
* [HUD and Information Improvements](hud-and-information-improvements.md) — interface changes including tab-list and armor information. **Mods:** Better Tab, uku's Armor HUD
* [Keybind Search](keybind-search.md) — search for controls. **Mod:** Controlling
* [Changed Options and Menu](../changed-options-and-menu.md) — details about Citron's custom main menu.

## Visual options

* [Extra Video Settings](extra-video-settings.md) — additional rendering and animation controls. **Mod:** Sodium Extra
* [Connected Textures](connected-textures.md) — connected-texture support for compatible resource packs. **Mod:** Continuity

## Performance

Citron's initial development records list performance-related mods including BadOptimizations and Clumps. See [Performance](../performance/) for guidance and check the exact version page for build-specific information.

> This index is based on Citron's development records. Confirm each feature against the version you use; development builds may add, remove, or change features.
