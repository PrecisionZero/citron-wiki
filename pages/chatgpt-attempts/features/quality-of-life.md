# Quality of Life

Quality-of-life features make everyday Minecraft actions more convenient without aiming to turn the game into a different experience.

Citron's approach is to evaluate the feature a mod provides rather than include a mod simply because it is popular. Extra functionality is worthwhile when it adds enough value to justify its complexity.

Each feature entry should briefly explain what the player can do, whether it has a default keybind or setting, and which mod provides it. Only document controls and behaviour verified in the relevant Citron build.
