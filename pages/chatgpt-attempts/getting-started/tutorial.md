# Tutorial

This guide takes you from installing Citron to launching a clean instance and making your first customisations.

## 1. Install Citron

Choose the launcher you want to use and follow the [Installation guide](../../installation/). Make sure the Citron build matches the Minecraft version you intend to play.

## 2. Launch it once

Start Citron before adding extra mods, shaders, or resource packs. This confirms that the base instance works and gives you a clean point to return to if a later change causes trouble.

## 3. Check the menu

Citron uses a custom main menu in the documented development build. If a button you need is missing, use the **Default Menu** option to switch back to Minecraft's default menu.

## 4. Set up your preferences

Adjust the controls and video settings you need. Citron includes selected mod configurations, so check [Changed Options and Menu](../features/changed-options-and-menu.md) if a menu option is in a different place or a setting behaves differently.

## 5. Add optional content

If you want extra mods, resource packs, or shaders, add them one at a time and test after each change. See Adding Extra Mods and Resource Packs and Shaders.

## 6. Keep your instance safe

Back up your worlds before updates or major changes. If something breaks, use [Troubleshooting](../help/troubleshooting.md) before reporting the issue.
