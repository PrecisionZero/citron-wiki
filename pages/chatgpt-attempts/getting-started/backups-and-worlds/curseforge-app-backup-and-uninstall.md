# CurseForge App — Backup and Uninstall

## Back up your files

1. Open CurseForge and go to **Minecraft → My Modpacks**.
2. Open the Citron profile menu and choose its folder-opening option.
3. Copy the files you want to keep to a separate location.

Consider backing up:

* `saves` — single-player worlds
* `screenshots` — screenshots
* `resourcepacks` — resource packs you added
* `shaderpacks` — shader packs, if present
* `config` — personal configuration changes
* `options.txt` — video settings and keybinds
* `servers.dat` — saved multiplayer server list

## Remove the profile

Once your backups are safe, use the profile menu in CurseForge to remove the instance. Check the confirmation dialog before proceeding, especially if it offers to delete associated files.

When reinstalling Citron, install a fresh profile and restore only the files you need.
