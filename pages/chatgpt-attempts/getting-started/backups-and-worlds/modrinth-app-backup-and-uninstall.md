# Modrinth App — Backup and Uninstall

## Back up your files

1. Open Modrinth and go to **Library**.
2. Open the Citron instance menu and choose the option to open its folder.
3. Copy the files you want to keep to a separate location.

Common items to back up:

* `saves` — single-player worlds
* `screenshots` — screenshots
* `resourcepacks` — resource packs you added
* `shaderpacks` — shader packs, if present
* `config` — personal configuration changes
* `options.txt` — video settings and keybinds
* `servers.dat` — saved multiplayer server list

## Remove the instance

After checking that your backups are safe, use the instance menu to remove the profile. Read the confirmation dialog carefully to see whether its files will also be deleted.

To reinstall Citron, follow the installation guide and restore only the files you need.
