# Backups and Worlds

Back up your worlds and personal files before updating Citron, changing Minecraft versions, or experimenting with extra mods.

Choose your launcher for specific steps:

* [Modrinth App — Backup and Uninstall](modrinth-app-backup-and-uninstall.md)
* [CurseForge App — Backup and Uninstall](curseforge-app-backup-and-uninstall.md)

Common files worth keeping include `saves`, `screenshots`, `resourcepacks`, `shaderpacks`, `config`, `options.txt`, and `servers.dat`, depending on what you use.

Keep backups outside the instance folder. If you uninstall an instance or remove its files, a backup stored inside that same folder may be deleted with it.
