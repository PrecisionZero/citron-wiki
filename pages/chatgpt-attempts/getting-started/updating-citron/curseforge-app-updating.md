# CurseForge App — Updating

Use the profile controls in CurseForge to manage Citron updates. Available options depend on which versions have been published.

1. Open CurseForge and select **Minecraft**.
2. Go to **My Modpacks** and select your Citron profile.
3. Open the profile's menu or version controls.
4. Choose the Citron file you want, if version selection is available.
5. Confirm the update or install the selected version, then wait for it to finish.
6. Launch Citron and check that your worlds and settings are intact.

> **Before updating:** Back up your worlds and personal configuration changes. For a different Minecraft version or development build, a separate profile is safer than overwriting a setup you rely on.

If Citron is not available in your CurseForge library, check the official project listing first. Do not install an unrelated modpack with a similar name.
