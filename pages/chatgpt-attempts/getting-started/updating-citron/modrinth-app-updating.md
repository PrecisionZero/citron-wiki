# Modrinth App — Updating

Use the Modrinth App to update an existing Citron instance. Button names may vary slightly between app versions.

1. Open Modrinth and go to **Library**.
2. Select your Citron instance.
3. Open the instance's version or update controls.
4. Choose the Citron build you want, if a newer compatible build is available.
5. Wait for the update to finish, then launch the instance.
6. Check that your worlds and settings are still present.

> **Before updating:** Back up important worlds and personal settings. Do not downgrade an instance containing worlds saved in a newer Minecraft version. For testing a different Minecraft version or development build, installing a separate instance is safer.

If an update option is missing, check the version details and the official Citron project listing to confirm that a newer compatible build is available.
