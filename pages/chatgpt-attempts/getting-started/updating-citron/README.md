# Updating Citron

You can update Citron through the launcher you used to install it. Before updating, check the release notes and make a backup of your worlds and any configuration files you changed.

Choose your launcher:

* [Modrinth App — Updating](modrinth-app-updating.md)
* [CurseForge App — Updating](curseforge-app-updating.md)

## After updating

Launch the new instance and check that your worlds, settings, and personal additions still work. Updates can change configuration defaults or replace files, so restore your preferences if necessary.

If you are switching Minecraft versions or trying a development build, install it as a separate instance when possible. Keep your old instance until the new one works as expected.
