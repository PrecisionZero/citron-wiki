# Updating Citron

Keep Citron updated through the launcher you used to install it. Available options and labels can differ between launchers.

## Before updating

1. Close Minecraft.
2. Back up important worlds and any configuration files you have customised.
3. Check the release notes for the version you plan to install.

## Update through your launcher

Open your Citron instance in the launcher and use its update or version-selection controls, if available. If the launcher cannot update the existing instance safely, install the new version separately and test it before removing the old one.

## After updating

Launch the updated instance and check that your worlds, settings, and any personal additions still work. Modpack updates may replace files or change configuration defaults, so restore your preferences if necessary.

If the update causes problems, try a clean instance before adding your personal modifications back.
