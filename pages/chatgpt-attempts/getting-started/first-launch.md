# First Launch

After installing Citron, launch it once before adding anything else. This makes it easier to tell whether a problem comes from the original pack or from later changes.

## Before launching

* Make sure the instance uses the Minecraft version and loader required by the Citron build you installed.
* Close other games or heavy applications if your computer is low on memory.
* If the game fails to start, check [Troubleshooting](../help/troubleshooting.md).

## Memory allocation

More allocated memory does not automatically mean better performance. Leave enough memory for your operating system and other applications. Start with the launcher's default allocation unless you have a reason to change it.

## After the first launch

Test Citron before adding extra mods, shaders, or resource packs. If you customize the instance, add changes one at a time so you can identify what caused a problem.
