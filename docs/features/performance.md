# Performance

Citron includes performance-focused mods, but results depend on your hardware, settings, world, and drivers.

## What can improve?

Performance mods may reduce rendering or game logic overhead, improve memory use, or help with loading. They cannot guarantee the same FPS on every system.

## Testing performance

1. Use the same world, location, and settings for each test.
2. Let the world finish loading.
3. Compare multiple runs, not a single FPS reading.
4. Change one setting at a time.

Average FPS is useful, but frame-time consistency matters too. A high average can still feel choppy if frames arrive unevenly.
