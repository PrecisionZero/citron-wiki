# Quality of Life

Citron includes small features that make everyday play more convenient while keeping the core game familiar.

Depending on the build, these may include HUD information, inventory improvements, keybind search, durability indicators, or zoom controls. Check the installed mod list for the exact features in your version.

## Finding controls

Open **Options → Controls** and search for the feature or mod name. If a control does not work, check for a keybind conflict.
