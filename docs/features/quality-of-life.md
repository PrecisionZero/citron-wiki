# Quality-of-Life Features

Quality-of-life (QoL) features reduce friction in everyday play without intending to replace Minecraft's core systems.

Depending on the installed version, Citron's feature set may include clearer status information, improved inventory interaction, more convenient keybind management, durability or armor indicators, and zoom or visual utility controls.

## How to use QoL features

- Open **Options → Controls** to review available keybinds.
- Search by a mod or feature name if the controls screen supports searching.
- Resolve duplicate keybinds before assuming a feature is broken.
- Review the feature's configuration screen, if provided by the mod.
- Disable or adjust optional behavior when it conflicts with your preferences.

The exact list may change between builds. Check [Included Mods](mods.md) and the configuration pages for the build you installed.
