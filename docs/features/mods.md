# Included Mods

This page explains how to read Citron's mod list and what broad categories of mods do. The exact inventory depends on the pack build; use the manifest or mod list bundled with the version you installed for a definitive list.

## Categories

| Category | Purpose |
|---|---|
| Performance | Reduce rendering, memory, entity, or game-loop overhead where possible. |
| Configuration and libraries | Provide settings screens, shared APIs, and dependencies used by other mods. |
| Interface and information | Improve menus, controls, status information, or HUD readability. |
| Visual compatibility | Help resource packs, rendering features, or shader integrations work together. |
| Convenience | Add small usability features without substantially changing core gameplay. |

## Selected components known from the development configuration

Citron's development history has included components such as Sodium, Iris, Sodium Extra, ModernFix, BadOptimizations, Clumps, AppleSkin, BetterF3, Controlling, Searchables, Shulker Box Tooltip, Zoomify, Continuity, LambDynamicLights, Mouse Tweaks, and FancyMenu, along with supporting libraries.

This list is a historical reference, not a guarantee that every named component is included in the current build. Check the exact pack manifest before adding or removing a mod.

## Adding mods

Extra mods are outside the default support baseline. Back up the instance, confirm the Minecraft and loader versions, and add one mod at a time. See [Compatibility](../compatibility/index.md).
