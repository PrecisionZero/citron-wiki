# Included Mods

Citron's mod list can change between builds. For an exact list, check the manifest or mods list that came with the version you installed.

## Mod categories

| Category | What it does |
|---|---|
| Performance | Reduces overhead in rendering, memory use, or game logic. |
| Libraries | Provides shared code that other mods need. |
| Interface | Adds controls, HUD information, or menu features. |
| Visuals | Supports rendering features and resource-pack compatibility. |
| Quality of life | Adds small usability improvements. |

## Examples from Citron's development

Development builds have included mods such as Sodium, Iris, Sodium Extra, ModernFix, BadOptimizations, Clumps, AppleSkin, BetterF3, Controlling, Searchables, Shulker Box Tooltip, Zoomify, Continuity, LambDynamicLights, Mouse Tweaks, and FancyMenu.

This is a development-history reference, not a promise that every mod is in every build. Check your instance before adding or removing anything.

## Adding mods

Extra mods can cause conflicts or duplicate existing features. Back up the instance and add one mod at a time.
