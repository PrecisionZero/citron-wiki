# Updating Citron

## Steps

1. Check the new version's Minecraft and Fabric requirements.
2. Close the game.
3. Back up your worlds and any configuration files you've changed.
4. Update the instance using your launcher, or import the new version as a separate instance.
5. Launch it before adding extra mods or resource packs.

Keeping the old instance until the new one works makes it easier to roll back.

## World safety

Back up worlds before changing Minecraft versions. A world saved in a newer version may not work correctly in an older one.
