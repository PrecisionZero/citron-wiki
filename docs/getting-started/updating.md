# Updating Citron

A controlled update makes it easier to recover if a mod, configuration, or Minecraft version changes.

1. Read the release notes and check the required Minecraft and Fabric versions.
2. Close Minecraft and the launcher instance.
3. Back up important worlds and any configuration files you edited.
4. Use the launcher's supported update or import process.
5. Do not copy an old mods folder over a new pack unless the release instructions explicitly require it.
6. Launch the updated instance without additional mods first.
7. Verify worlds and settings before deleting the backup.

## Keep worlds safe

Make a separate backup before changing Minecraft versions. A world opened in a newer version may not be safely usable in an older version afterward.

## If the update breaks

Keep the old instance until the new one is confirmed working. See [Launch and Crashes](../troubleshooting/launch-crashes.md) and [Reading Logs](../troubleshooting/logs.md).
