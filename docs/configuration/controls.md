# Controls and Keybinds

Mods can add their own controls to Minecraft's controls screen.

## Find or change a key

1. Open **Options → Controls → Key Binds**.
2. Search for the feature or mod, if a search field is available.
3. Look for conflicting bindings.
4. Assign an unused key.

If a feature's keybind is missing, check whether the relevant mod is included in your version.
