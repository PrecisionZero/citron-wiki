# Controls and Keybinds

Many mods add controls to Minecraft's standard controls screen.

## Find a keybind

1. Open **Options → Controls → Key Binds**.
2. Search for the feature or mod name if a search field is available.
3. Look for duplicate bindings or a conflict indicator.
4. Assign an unused key and apply the change.

## Resolve conflicts

Two actions assigned to the same key may both trigger or may be blocked by the game, depending on the mod. Choose a distinct key for each action you use regularly.

If a keybind is missing, verify that the relevant mod is actually present in your installed build. The wiki's [Included Mods](../features/mods.md) page is a guide, not a substitute for checking the exact mod list.
